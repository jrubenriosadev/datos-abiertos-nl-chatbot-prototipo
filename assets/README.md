# Assets

Imágenes del proyecto. Todo es opcional por ahora.

- `mascota.png` o `mascota.svg`: el personaje del chat (PNG con fondo transparente o SVG). Cuando lo agregues, activa `avatarUrl` en la configuración al final de `frontend/index.html`.
- `reference/`: capturas del portal que usas como referencia visual. Son para ti; no se publican ni se copian a la maqueta.

No metas aquí archivos de datos (van en `data/`) ni claves.
